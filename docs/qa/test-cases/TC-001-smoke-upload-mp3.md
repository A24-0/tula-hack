# TC-001: Smoke — загрузка mp3 через UI

**ID:** TC-001
**Модуль:** Frontend + Backend /upload
**Приоритет:** High
**Вид:** Smoke / позитивное / чёрный ящик / ручное

## Предусловия
- `docker compose up --build` завершён, все контейнеры healthy.
- Готов файл `samples/ok_ru_30s.mp3` (≈30 сек русская речь без PII).

## Шаги
1. Открыть `http://localhost:3000` в Chrome 120+.
2. Нажать «Загрузить файл», выбрать `ok_ru_30s.mp3`.
3. Подтвердить отправку.
4. Наблюдать индикатор прогресса.

## Ожидаемый результат
- `POST /upload` → 202, тело `{"job_id": "<uuid>"}`.
- Фронт начинает polling `/jobs/<id>` каждые ~1.8с.
- В течение ≤ 60с статус переходит `queued → processing → done`.
- Появляется блок транскрипции и кнопки «Исходное аудио» / «Аноним. аудио».

## Постусловия
- В `${UPLOAD_DIR}` создан файл `<uuid>.mp3` и `<uuid>_redacted.mp3`.
