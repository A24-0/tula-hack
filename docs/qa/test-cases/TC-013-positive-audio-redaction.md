# TC-013: Заглушение аудио точно совпадает со словами PII

**ID:** TC-013
**Модуль:** ai-service/audio_redact.py + ner.py
**Приоритет:** High
**Вид:** Функциональное / позитивное / серый ящик / ручное

## Предусловия
- TC-002 пройден.

## Шаги
1. Из результата TC-002 взять первое событие `PHONE` со `start_sec`, `end_sec`.
2. Открыть `/audio/<id>/redacted` в аудиоредакторе (Audacity).
3. Сравнить диапазон `[start_sec; end_sec]` с аналогичным в оригинале.
4. Повторить для `INN` и `PERSON`.

## Ожидаемый результат
- В redacted-файле диапазон `[start_sec; end_sec]` — RMS < −50 dBFS (тишина).
- Разница границ между оригиналом и redacted ≤ 100 мс.
- Слова вне PII-диапазонов звучат без искажений.
