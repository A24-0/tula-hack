# TC-007: Регресс — потеря job'ов при рестарте backend

**ID:** TC-007
**Модуль:** backend/internal/service.Store (in-memory)
**Приоритет:** High
**Вид:** Регрессионное / серый ящик / ручное

## Предусловия
- Сервисы подняты.

## Шаги
1. Загрузить файл, получить `job_id`.
2. Дождаться `status=done`.
3. Выполнить `docker compose restart backend`.
4. Запросить `GET /jobs/<job_id>` и `GET /transcript/<job_id>`.

## Ожидаемый результат (согласно требованию надёжности)
- Job'ы сохранены (например, в БД или на диске), `/jobs/<id>` возвращает 200.

## Фактический результат (по коду)
- `/jobs/<id>` → 404 «job not found», т.к. store in-memory.
- **Фиксируется как баг BUG-001 (High).**

## Результат выполнения
**Дата:** 2026-04-19
**Статус:** Failed
**Фактический результат:** После рестарта `/jobs/<id>` вернул 404, `/transcript/<id>` вернул 404. Исходный аудиофайл в volume сохранился, но связь с job'ом утрачена.
**Связанные баги:** BUG-001
