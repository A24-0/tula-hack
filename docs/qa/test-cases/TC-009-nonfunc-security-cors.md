# TC-009: Безопасность — утечки PII и MaxBytesReader

**ID:** TC-009
**Модуль:** Backend + ai-service
**Приоритет:** High
**Вид:** Нефункциональное (безопасность) / чёрный ящик / ручное

## Шаги
1. Прогнать TC-002 с PII-файлом.
2. Собрать логи: `docker compose logs backend ai-service > qa_logs.txt`.
3. Грепом проверить отсутствие распознанных значений PII (конкретный номер телефона/ИНН) в логах.
4. Проверить, что `POST /upload` без `Content-Length` и с chunked отсекается `MaxBytesReader` при > 500 МБ.
5. `curl -H "Origin: http://evil.example" -i http://localhost:8080/jobs/deadbeef` — проверить CORS-заголовки.

## Ожидаемый результат
- В логах нет конкретных значений PII, только маски/типы.
- CORS ограничен настройкой (или отсутствует `Access-Control-Allow-Origin: *` на приватных эндпоинтах).
