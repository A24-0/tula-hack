# TC-002: Позитивный end-to-end с PII

**ID:** TC-002
**Модуль:** Весь пайплайн
**Приоритет:** High
**Вид:** Функциональное / позитивное / динамическое / ручное

## Предусловия
- Сервисы подняты. `GIGACHAT_API_KEY` задан в `.env`.
- Файл `samples/pii_ru_1min.wav` с речью: «Меня зовут Иван Петров, телефон плюс семь девятьсот, ИНН семь семь семь семь семь семь семь семь семь семь».

## Шаги
1. Загрузить `pii_ru_1min.wav` через UI.
2. Дождаться `status=done`.
3. Открыть `GET /transcript/<id>` и `GET /logs/<id>`.
4. Прослушать `/audio/<id>/redacted`.

## Ожидаемый результат
- `transcript` содержит распознанный текст.
- `redacted_transcript` имеет маски вместо PHONE, INN, PERSON.
- `logs` содержит события с типами `PHONE`, `INN`, `PERSON` и полями `start_sec`, `end_sec`.
- На участках `[start_sec;end_sec]` в redacted-аудио слышна тишина, остальная речь — без изменений.
